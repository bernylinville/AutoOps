# Design System

> UI 样式、颜色、排版、组件修改时阅读。

本文档内容源自 `.impeccable.md`，定义 AutoOps 的视觉和交互标准。

## 设计原则

1. **Clarity Over Beauty** — 3 秒内在 Dashboard 上获取关键信息
2. **一致性即精致** — 统一间距、颜色、交互模式
3. **Dashboard 即态势感知** — 扫一眼知全貌
4. **有目的的动效** — 过渡 ≤ 300ms，只在状态变化时使用
5. **校准的信息密度** — 运维场景需要高密度但不杂乱
6. **品牌存在但不喧宾夺主** — 企业工具定位，非产品展示

## 目标用户

运维工程师、开发工程师、SRE、交付工程师、管理员。桌面端优先，长时间使用场景。

## 美学方向

**克制的现代工业美学**，亮色模式为主（可选暗色用于夜班）。

**反面参考**（避免）：SaaS 着陆页风格、AI 炒作美学、过度圆角/渐变。

## 色彩系统

| 用途 | 色值 |
|------|------|
| 主色 | Element Plus 默认蓝 `#409EFF` |
| 成功 | `#67C23A` |
| 警告 | `#E6A23C` |
| 危险 | `#F56C6C` |
| 信息 | `#909399` |

ECharts 调色盘见 `.impeccable.md` Lines 196-216。

## 排版

- 字体族：系统字体栈（-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif）
- 正文：14px / 1.6 行高
- 标题层级：20px → 18px → 16px → 14px

## 间距系统

8px 基准网格：

| Token | 值 | 用途 |
|-------|-----|------|
| xs | 4px | 图标与文字间距 |
| sm | 8px | 表单元素内间距 |
| md | 16px | 卡片内间距 |
| lg | 24px | 区块间距 |
| xl | 32px | 页面级间距 |

## 组件约定

- **Sidebar**：宽 210px（折叠 64px），深色背景
- **Table**：斑马纹、固定表头、行高 48px
- **Form**：标签右对齐、标签宽 100px、必填项红色星号
- **Dialog**：宽 600px（小）/ 800px（中）/ 1000px（大），顶部 15vh
- **Button**：主操作在右侧，确认蓝色/取消灰色

## 技术约束

- UI 框架：Element Plus 2.x（不引入其他 UI 库）
- 图表：ECharts 5.x
- 图标：@element-plus/icons-vue（不引入外部图标库）
- 构建：Vue CLI 5
- 主分辨率：1920×1080，最小支持 1366×768
