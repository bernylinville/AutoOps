# 运维知识库 (Knowledge Base) — Product Spec

**Issue:** 后续规划 P2 — 运维知识库 (Markdown + PG 全文搜索)
**Figma:** none provided (纯文本界面，无特殊 UI 设计)

## Summary

为 AutoOps 添加运维知识库功能，支持 Markdown 格式的知识文档创建、编辑、分类和全文搜索。使用 PostgreSQL 全文搜索 (GIN 索引) 实现高性能检索，无需引入 Elasticsearch 等外部依赖。

## Problem

当前运维经验和故障处理方案分散在个人笔记、聊天记录或口头传承中：
- 新人遇到已知问题时重复询问，缺乏统一查询入口
- 故障恢复后未沉淀为可复用文档
- CMDB 变更、部署流程等操作手册无版本化管理

## Goals / Non-goals

**Goals:**
- 支持 Markdown 知识文档的 CRUD 操作
- 按分类（故障处理、操作手册、最佳实践）组织文档
- PostgreSQL 全文搜索，支持标题+内容检索
- 简单的权限控制（创建者/管理员可编辑）

**Non-goals:**
- 不实现富文本编辑器（保持 Markdown 纯文本）
- 不实现文档版本历史（仅保存最新版本）
- 不实现文档协作编辑（单人编辑锁）
- 不实现文件附件上传

## Behavior

1. **文档列表页**
   - 默认展示所有文档，按更新时间倒序
   - 左侧显示分类树（全部 / 故障处理 / 操作手册 / 最佳实践）
   - 顶部搜索框支持标题+内容全文搜索
   - 每篇文档显示标题、分类、作者、更新时间和摘要（前 200 字符）

2. **文档搜索**
   - 输入关键词后实时搜索（防抖 300ms）
   - 搜索结果按相关度排序（PG ts_rank）
   - 关键词在结果中高亮显示
   - 无结果时显示空状态提示

3. **文档创建**
   - 点击"新建文档"进入编辑页
   - 必填：标题（≤128 字符）、内容（Markdown）
   - 必选：分类（下拉选择）
   - 可选：标签（多选，用于辅助筛选）
   - 保存后跳转到文档详情页

4. **文档编辑**
   - 仅文档创建者或管理员可编辑
   - 编辑时显示"最后修改时间"
   - 保存时校验标题唯一性（同分类下不可重复）

5. **文档详情**
   - 左侧：文档内容（Markdown 渲染为 HTML）
   - 右侧：元信息（作者、时间、分类、标签）
   - 底部：相关文档推荐（同分类的最新 5 篇）

6. **分类管理（管理员）**
   - 预置分类不可删除（故障处理、操作手册、最佳实践）
   - 可添加自定义分类
   - 分类下有文档时不可删除

## Edge Cases

- **空内容保存**: 内容为空时提示"请输入文档内容"
- **标题重复**: 同分类下标题重复时提示"该分类下已存在同名文档"
- **特殊字符搜索**: 搜索包含 SQL 注入尝试的字符串时，使用参数化查询防护
- **大量文档**: 列表页分页，每页 20 条
- **并发编辑**: 乐观锁（version 字段），保存时校验版本号
- **删除恢复**: 软删除（deleted_at），管理员可恢复

## Success Criteria

1. 用户可以创建、编辑、删除 Markdown 知识文档
2. 全文搜索能在 500ms 内返回结果（1000 篇文档以下）
3. 搜索结果按相关度排序，关键词高亮
4. 分类筛选和搜索可组合使用
5. 仅创建者/管理员可编辑文档

## Open Questions

- 是否需要支持文档导出（PDF/Markdown 文件）？
- 标签系统是否需要预定义标签，还是完全自由输入？
